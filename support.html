File access

If a file shows “Permission Needed,” stop tracking it and add it again from Finder. FileExpiry uses macOS security-scoped access only for files you choose.

Files that were moved or renamed

macOS bookmarks may follow many Finder moves and renames. If FileExpiry can no longer resolve a file, it marks it as missing instead of deleting anything else.

Restore Lifetime Pro

Open FileExpiry Settings, choose About, and click Restore Purchases. Make sure the Mac App Store is signed in to the Apple Account used for the original purchase.

Where expired files go

FileExpiry moves expired files to the macOS Trash. Open Trash in Finder if you need to restore one.
